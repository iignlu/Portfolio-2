# Abdullah Alshehri — Portfolio

My personal portfolio site. Built with vanilla HTML, CSS, and JavaScript.

## Tech Stack

- HTML5, CSS3, JavaScript
- Font Awesome (icons)
- Google Fonts (Inter, Space Grotesk, JetBrains Mono)

## Features

- Warm amber-on-dark color palette
- Code editor mockup with typing animation
- Tech stack display with real tools I use
- Scroll-triggered reveal animations
- Responsive across all screen sizes
- Contact form (Netlify)

## Structure

```
├── index.html
├── style.css
├── script.js
├── CV_Abdullah.pdf
└── README.md
```

## Run Locally

```bash
git clone https://github.com/iignlu/Portfolio-2.git
cd Portfolio-2
open index.html
```
