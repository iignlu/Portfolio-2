# Abdullah Alshehri | Portfolio

Welcome to my personal portfolio repository! This project showcases my journey as a Full-Stack Developer, my skills, professional experience, and the projects I've built.

I'm a full-stack developer and AI enthusiast specializing in creating responsive, user-friendly web applications. I leverage cutting-edge AI tools to build robust systems using modern frameworks like React and Laravel, delivering efficient and intelligent digital solutions.

- 🎓 **Education:** Bachelor of Computer Science at Jubail Industrial College (2021 – 2026).

## 🛠️ Tech Stack

This portfolio is built using:
- **HTML5** & **CSS3** (with custom properties and modern layout techniques).
- **JavaScript** (Vanilla) for dynamic interactions and particle effects.
- **AI Tools** (leveraging advanced AI for development and feature implementation).
- **AOS (Animate On Scroll)** for smooth entrance animations.
- **Font Awesome** for iconography.
- **Google Fonts** (Inter & Space Grotesk) for typography.
- **Canvas API** for the interactive background particles.

## ✨ Key Features

- **Responsive Design:** Fully optimized for all screen sizes, from mobile to desktop.
- **Interactive UI:** Features a custom particle background and typing animations.
- **Project Showcase:** Detailed cards for my web development and UI/UX projects.
- **Contact Form:** Integrated for direct communication (configured for Netlify).
- **CV Download:** Easy access to my professional resume.
